## Order confirmation

You'll see an on-screen confirmation once your order is placed. This
storefront is a portfolio demo without a live checkout/payment step or
order-confirmation email yet — cart contents are currently saved in your
browser's local storage only, not in a backend order system.

## Processing time

In-stock items are typically packed within 1–3 business days of payment
confirmation, then handed to the courier. See the Shipping (Philippines)
policy for delivery timelines after dispatch.

## Combined shipments

Multiple in-stock items in the same order are packed together into one
parcel wherever possible, to save on shipping cost. If an order mixes
in-stock and preorder items, see the Preorder Policy for how that's
handled.

## Order changes

Item selections (which product, which version, quantity) can only be
changed before an order is packed for dispatch. Once packing has started,
changes are no longer possible — you'd need to cancel (if still eligible)
and place a new order, or handle it as a return once received.
