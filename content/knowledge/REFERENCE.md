# Source note (not ingested)

The policy documents in this folder are **original Idol Fairies PH content**,
written for this project and adapted to a Philippines-based storefront
(local courier timelines, PHP pricing, no cross-border customs on domestic
delivery).

Their **topic structure** — shipping, wholesale & bulk orders, order
processing, cancellation, returns/refunds, damaged/missing items, payment,
address changes, customs/import duties, general FAQs — is informed by the kind of
help-center structure common to K-pop resale storefronts, including K PLACE
(https://help.kplaceshop.com/hc/en-us), which was reviewed only for topic
shape, not copied for wording. Idol Fairies PH is not affiliated with K
PLACE, and the chatbot must never claim otherwise or answer as if it were K
PLACE.

This file itself is excluded from ingestion (see `scripts/ingest-knowledge.ts`)
— it documents provenance, it isn't customer-facing policy content.
